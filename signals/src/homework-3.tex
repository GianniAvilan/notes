		\item
			\begin{enumerate}[label=\alph*)]
				\item BIBO stability is determined based on whether the input is bounded for a bounded output. In this example, if the bounded input \(x[n-1] = 0\), \(y[n+1]\) approaches infinity, and so the system is BIBO-unstable.
				\item Adjusting the system to be in \textit{delay} form, 
					\[
						y[n] = \frac{x[n-1]}{x[n]},
					\]
					we can see clearly that the system relies on inputs prior to the present input at \(n=0\), and so the system is \textbf{not} memoryless.
				\item Since the system does not depend on \textbf{future} values of \(x[n+1]\), the system can be considered \textbf{causal}.
			\end{enumerate}
